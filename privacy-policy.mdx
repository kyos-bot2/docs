Kyos’ Privacy Policy

**Last updated:** 24th of March 2025

---

## Data We Store

Kyos stores the following data to ensure proper functionality and customization for your server:

- Guild (Server) IDs – Used to identify and apply settings specific to each server.
- Channel IDs – For associating certain features or configurations with specific channels.
- User IDs – To store user-specific settings, preferences, or historical data.
- Role IDs – For role-based configurations and feature restrictions.
- Message IDs – To track and reference specific messages when necessary.
- Message Content – Collected when required for features like note-taking or moderation tools.
- Message Timestamps – Stored temporarily (up to 2 hours) for moderation logs or audit purposes.
- Message Deletion Times – Stored temporarily (up to 2 hours) for snipe and anti-abuse purposes.
- Reaction Removal Times & Removed Emoji(s) – Stored temporarily (up to 2 hours) to support moderation and reaction tracking features.
- Command Usage Logs – Includes server ID, user ID, command executed, and execution timestamp. Stored for a maximum of 14 days to provide analytics, improve bot features and trace abuse.
- Server Nicknames – Stored to support the namehistory feature. Users can clear their stored nickname history at any time using the `clearnames` command.

---

## Important

We do not store sensitive information such as passwords, payment details, IP addresses, or email addresses. All stored data is used solely to provide, maintain, and improve Kyos’s functionality.

---

## Who is your information shared with?

We do not sell, trade, or share your personal information with third parties. Your data is only accessible to authorized Kyos team members and used solely to provide and improve bot functionality.

---

## Why we store the data we do

When a command is invoked, we increment the value of times it is used by one for the `topcommands` command to function. This command does not show any information routing back to you.

Guild IDs, Channel IDs, Role IDs, User IDs and Message IDs are all stored for the bot to locate data based on your server and/or user.

Features such as **server nicknames** are stored in order for the `namehistory` command to work. You may clear your history at any time using the `clearnames` command.

---

## Data Removal

To request deletion of your data, you may:

- Open a ticket in our official Discord support server and provide proof of ownership (e.g., matching Discord tag and user ID, server ownership).
- Email: kyos-bot@proton.me with valid proof of account or server ownership.

Please note: If you request server-wide data deletion, your server will be blacklisted from using Kyos services to prevent future data collection.

We will respond to all data requests within 21 days. Response time may take up to 3 weeks.
